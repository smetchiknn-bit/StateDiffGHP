# StateDiff — Форма БылоСтало (для СУ)

Мастер сравнения листов ИД КЕР и ИД ТМЦ двух СР (Было и Стало). На выходе создает таблицу БылоСтало по форме Сметного Управления.

## 🚀 Деплой на GitHub Pages

Приложение настроено для автоматического деплоя на GitHub Pages через GitHub Actions.

### Настройка GitHub Pages:

1. Перейдите в **Settings** → **Pages** вашего репозитория на GitHub
2. В разделе **Source** выберите **GitHub Actions**
3. После push в ветку `main` приложение автоматически соберётся и задеплоится

### URL приложения:
```
https://<username>.github.io/StateDiff/
```

### Как это работает:
- При каждом push в `main` запускается GitHub Actions workflow (`.github/workflows/deploy.yml`)
- Workflow устанавливает зависимости, собирает проект через Vite и загружает `dist/` на GitHub Pages
- Приложение доступно по адресу `https://<username>.github.io/StateDiff/`

## 📋 Функциональность

1. **Загрузка файлов** — загрузите два Excel-файла (БЫЛО и СТАЛО) с листами "СМР уник" и "ТМЦ уник"
2. **Проверка** — отображаются контрольные суммы для проверки корректности данных
3. **Сравнение** — приложение сопоставляет коды и рассчитывает разницы
4. **Отчёт** — отображается таблица с результатами и возможностью экспорта в Excel
